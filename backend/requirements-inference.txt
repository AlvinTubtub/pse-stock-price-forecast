# Lightweight dependency set for daily inference only.
#
# Used by the Fast Pipeline (.github/workflows/update_pipeline.yml)
# after data ingestion, to load persisted weekly models and generate
# fresh next-trading-day forecasts without retraining.
#
# Versions are pinned to match the environment that actually produced the
# currently-persisted artifacts (models/lag_regression/*.pkl,
# models/arima/*.pkl, models/lstm/*.pth) — verified 2026-08-10 by
# inspecting the pickled artifacts directly (sklearn embeds
# `_sklearn_version` in every LASSO artifact; the ARIMA artifacts'
# internal pandas Index/state and statsmodels result-wrapper classes only
# unpickle cleanly under these versions) and by loading all 15 tickers'
# artifacts of all 3 model types end-to-end under this exact pin set.
#
# The PREVIOUS pins in this file (pandas==2.0.3, numpy==1.24.4,
# scikit-learn==1.3.2, scipy==1.11.4, statsmodels==0.14.0, torch==2.0.1)
# do NOT match the persisted artifacts and will fail to load them:
#   - pandas<3 cannot unpickle the ARIMA artifacts' internal pandas Index
#     (they were pickled with pandas' newer default string dtype).
#   - statsmodels<0.14.6 raises `TypeError: deprecate_kwarg() missing
#     1 required positional argument` on import under pandas 3.x.
#   - scikit-learn 1.3.2 does not match the `_sklearn_version: '1.9.0'`
#     embedded in every models/lag_regression/*.pkl artifact.
#
# Do NOT change these pins without also retraining all models (weekly
# training must then be re-pinned to match, so training and inference
# stay on one reproducible environment — see requirements-pipeline.txt).
pandas==3.0.5
numpy==1.26.4
scikit-learn==1.9.0
scipy==1.17.1
statsmodels==0.14.6
torch==2.13.0
joblib==1.5.3
